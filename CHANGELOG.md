# What's new

## v1.1.10 · 3 November 2026

- The app now remembers every room you have joined. The start screen lists them with the exercise, whether you solved it or how many tests pass, and when you last opened it. Click one to go back in.
- While working, click the room code at the top to switch to another of your rooms, or choose "Add new room…" to type a new code. The app checks the code as you type and shows which exercise it is and whether the room is open.
- Going back into a room keeps you as the same student on the teacher's screen instead of adding you again.
- If a room has been closed or deleted, or there is no internet, the app still opens your saved code so you can keep practising. Your results are not sent while you are offline.

## v1.1.9 · 3 November 2026

- You can drag the borders between the description, your code, the 3D viewport and the test results to resize them. Each border is a thin line that gets thicker when you point at it.
- The button that hides the description now sits next to its title, so the description and your code use more of the screen.
- Make the code bigger or smaller with Ctrl and + / - (Ctrl and 0 resets it, Ctrl and the mouse wheel works too); the app remembers your size.
- The 3D viewport now has Z pointing up, like Rhino, and its Front, Right and Top views match Rhino's.
- The Join Room button is now next to the room code box.

## v1.1.8 · 3 November 2026

- Teachers can open the reference solution straight from a room's page.
- Exercise descriptions in the "View description & solution" window now look the same as in the room view.
- The "View description & solution" window closes when you click outside it.
- A room's page now also lists the exercises in a folded "Start another room" section at the top, so you can start a new room without leaving.
- The site icon now shows on every page, not only the home page.
- The website now spells the name "Aristeia", like the app.

## v1.1.7 · 2 November 2026

- New 3D exercise "Grid with Attractors": build your own Grid class and watch spheres shrink near attractors and grow near repulsors.
- The 3D viewport can now show spheres, and draws attractor and other input points as red dots you move with sliders.

## v1.1.6 · 2 November 2026

- Updated dependencies, including the components behind the 3D viewer, to their latest bug-fix releases.

## v1.1.5 · 2 November 2026

- Five new practice exercises: Arrays and Lists, Casting, Vector Math, Points in a Row and Zigzag Points
- Vectors can be used in exercises the same way as in Rhino and Grasshopper
- Exercises with a 3D view can take vector inputs, shown as X, Y and Z sliders
- `Print(...)` works like in Grasshopper, and printed output now appears in its own Print tab
- If the app crashes, a pop-up offers to open the crash log
- Teachers see how many tests each student passes, e.g. "In Progress · 7/11 tests"

## v1.1.4 · 2 November 2026

- Downloads are now named Aristeia, for example Aristeia-win-x64.zip.

## v1.1.3 · 2 November 2026

- The app window and the app's name in Task Manager and the macOS menu now say Aristeia.

## v1.1.2 · 2 November 2026

- The app is now called Aristeia: start it with Aristeia.exe (CodingExerciseClient.exe still works).
- New downloads unzip to a folder without a version number, so the folder name stays right as the app updates itself.

## v1.1.1 · 2 November 2026

- New exercise: Parking Fee Calculator, which is finished only when the answers are right and the code is split into small helper methods.
- Exercises can now check how code is structured, not just whether the answers are right. Test results show correctness and structure as two separate parts.

## v1.1.0 · 2 November 2026

- The app now tells you when a new version is out and can update itself with one click, then puts you back in your room with your code.
- A "What's new" button shows what changed in each version.
- Teachers can see which app version each student is using, and can require a minimum version from the new Settings page.

## v1.0.8 · 26 October 2026

- When your code compiles, a small picture of your 3D view is saved with your work, so your teacher can see what you built.
- Teachers can now open an exercise's description and its solution in one window.

## v1.0.7 · 26 October 2026

- Every exercise now has a checked reference solution, so you can be sure each one can be solved.
- Teachers can view the reference solution for any exercise.
