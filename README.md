# Aristeia client releases

Desktop client builds for Aristeia. This repository holds release files only; it is published by CI from a private repository.

Download the latest version from the [Releases](../../releases/latest) page. Releases named `pr-<number>` are temporary preview builds.

## What's new

[CHANGELOG.md](CHANGELOG.md) lists what changed in each version, newest first, written for students and teachers. The desktop client shows this file when you press **What's new**, so add an entry for every release.
